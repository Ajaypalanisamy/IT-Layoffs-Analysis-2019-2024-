📊 IT Layoffs Analysis (2019–2024)
🔍 Project Overview

This project analyzes global IT layoffs from 2019 to 2024 to uncover trends across years, countries, industries, and companies.
The goal is to transform raw layoff data into clean, structured data and present actionable insights using SQL, Excel, and Power BI.

This project follows a complete data analytics lifecycle:

Raw Data → Data Cleaning → Analysis → Visualization → Insights

🛠 Tools & Technologies Used

SQL (MySQL) – Data cleaning, transformation, and analysis

Microsoft Excel – Data validation and preprocessing

Power BI – Interactive dashboards and KPI reporting

🧹 Data Cleaning (SQL)

Performed extensive data cleaning using SQL:

Removed duplicate records

Handled missing and null values

Standardized company names, countries, and industries

Converted date formats

Created derived columns (Year, Month)

Validated employee layoff counts

📌 This step ensured accurate and reliable analysis.

📈 Data Analysis

Key analysis performed:

Year-wise layoff trends (2019–2024)

Top companies with highest layoffs

Country-wise and industry-wise impact

Layoff distribution by time period

Pre vs post market trend observations

📊 Power BI Dashboards

Created 5 interactive Power BI reports featuring:

KPI cards (Total Layoffs, Companies, Countries)

Yearly & monthly trend analysis

Top affected industries and companies

Country-wise heatmaps

Dynamic filters & slicers

Each dashboard answers:

What happened?

Why it happened?

How trends changed over time?

💡 Key Insights

Layoffs peaked during major market downturns

Certain industries were consistently affected

Specific countries and companies showed recurring layoff patterns

Post-pandemic years showed significant volatility
